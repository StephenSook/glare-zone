# Third-party notices

Glare Zone is a Lens Studio 5.23.2 project for Snap Spectacles (SPECS 27). This file lists what in the project came from someone else, where it came from, and what licence information ships with it. Versions are as installed on 2026-11-02, read from Lens Studio's package list and each package's `package_dependencies.json`.

None of the Lens Studio packages below contains a licence file. Where this file says "no licence file in the package", the terms are whatever Snap Inc. attaches to Lens Studio and its Asset Library; this project does not restate or change them.
